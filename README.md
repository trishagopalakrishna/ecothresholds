# ecothresholds
This repository contains the scripts that were generated as part of the study
estimating ecosystem transitions across the Cerrado, Brazil's savanna biome. 

All scripts are in 8 subfolders in Scripts > Final_Scripts, numbered indicating the order in which the scripts 
can be run.

Note that there are additional Scripts folders titled "DELETE AFTER PUBLICATION" which includes additional scripts/code for the author's usage and will be deleted once the manuscript is accepted for publication.
